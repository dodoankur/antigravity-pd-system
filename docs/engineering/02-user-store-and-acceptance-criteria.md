# 02. User Stories & Acceptance Criteria

## User Stories
- **US1:** As a first-time buyer, I want to measure my PD without a ruler so I can order glasses immediately.
- **US2:** As a developer, I want a clear API response with confidence scores so I can decide whether to trust the result.

## Acceptance Criteria
- **AC1:** The system must return a result within 2.5 seconds on a 5Mbps connection.
- **AC2:** The UI must handle camera permission denials gracefully with a fallback instruction.
- **AC3:** Accuracy must be within 1.0mm when compared to a standard pupilometer.
