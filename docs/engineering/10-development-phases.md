# 10. Development Phases

## Phase 1: Prototype (Weeks 1-4)
- MediaPipe integration in Next.js.
- Basic math for iris-based scaling.
- Simple UI for capture.

## Phase 2: Refinement (Weeks 5-8)
- Server-side scoring engine with sub-pixel accuracy.
- Error handling for low-light and occlusion.
- Accuracy study with 50 test subjects.

## Phase 3: Production Readiness (Weeks 9-12)
- Infrastructure setup (Docker/K8s).
- Monitoring and logging (Sentry/Grafana).
- Load testing (k6).
