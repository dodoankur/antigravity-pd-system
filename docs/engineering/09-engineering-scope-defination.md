# 09. Engineering Scope Definition

## In-Scope
- Browser-based PD measurement (Chrome, Safari, Firefox).
- Iris-based (card-less) scaling.
- Monocular and Binocular PD results.
- Real-time user guidance system.

## Out-of-Scope
- Virtual Try-On (VTO) for frames (Future phase).
- Prescription (Rx) verification.
- Storage of raw user photos (only landmarks and derived metrics are stored).
- Native mobile apps (MVP is Web-only).
